# SpendWise 💰

A student expense tracker built with the MERN stack to help manage income and expenses in one place.

## 🚀 Features

- Add, edit and delete income
- Add, edit and delete expenses
- Search income and expenses
- Pagination for income and expenses
- Income and expense statistics
- Income vs Expenses chart
- Expense category analysis
- Monthly financial insights
- Responsive dashboard
- MongoDB data storage

## 🛠️ Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- Recharts
- Lucide React
- shadcn/ui

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Indrajit-barui/SpendWise.git
```

### 2. Go into the project

```bash
cd SpendWise
```

### 3. Install frontend dependencies

```bash
npm install
```

### 4. Install backend dependencies

```bash
cd Backend
npm install
```
## 🔐 Environment Variables

Create a `.env` file inside the `Backend` folder:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000

## ▶️ Run the Project

### Start the backend

From the `Backend` folder:

```bash
node server.js
```

### Start the frontend

Open another terminal and run:

```bash
cd SpendWise
npm run dev
```
